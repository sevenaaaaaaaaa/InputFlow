# InputFlow PRD

> 一句话：**没有任何服务器参与的输入法**——引擎在本地，词库在本地，设备之间靠二维码配对、在局域网里直连同步。

## 1. 目标与非目标

| 目标 | 非目标 |
|---|---|
| 输入体验对标系统输入法（拼音/双拼/英文/日语） | 不做云词库、不做用户画像、不做广告 |
| 同步只在用户设备间发生（E2EE、无中继） | 不做账号体系、不做云端备份 |
| 桌面端有原生质感（Liquid Glass）与桌宠形态 | 不做皮肤商城/社区内容分发 |
| 六平台（mac/Win/Linux/Android/iOS/HarmonyOS） | M0-M3 不覆盖移动端全部机型兼容性打磨 |

## 2. 用户故事

1. **隐私敏感者**：安装后断网可用；防火墙里看不到任何出站连接；iOS 不授权 Full Access。
2. **多设备用户**：手机上复制 → 电脑上粘贴；新词在一台设备学会，其他设备自动生效；配对只需扫一次码。
3. **双拼用户**：小鹤/微软/自然码开箱即用，用户词与个人习惯随设备走。
4. **个性化用户**：候选窗是 Liquid Glass；桌面有一只桌宠，可吸附候选条/剪切板历史。

## 4. 设计契约（继承 OpenFlow / ThirdC）

- 颜色全部 oklch，零 hex；圆角三档 26/18/12；动效统一弹簧 `cubic-bezier(.32,.72,0,1)`；`prefers-reduced-motion` 下即时。
- 字体：Space Grotesk（界面）+ JetBrains Mono（元信息）+ 系统中文回退。
- 苹果平台用原生 Liquid Glass（`NSGlassEffectView` / SwiftUI `glassEffect`），其他平台用「模糊 + 饱和度 + 高光 + 噪点」近似，参数由 `docs/design-tokens.json` 单一来源生成。
- 图标：24×24 线框，`stroke-width:1.8`，圆角端点，不直出 emoji。

## 5. 关键产品决策

| 决策 | 理由 |
|---|---|
| 默认零网络权限（macOS 无网络 entitlement，iOS 无 Full Access） | 隐私叙事可信、可验证；同步作为显式开关 |
| 同步 = 二维码配对 + 局域网直连 | 无服务器、无账号、无 NAT 依赖；异地场景留给 M5 的自托管中继（默认关闭） |
| 桌宠是「候选条的另一形态」而非玩具 | 一个渲染管线两用，避免功能孤岛 |
| 词典格式开放（TSV / Rime `.dict.yaml` 导入） | 用户可以带自己的词库，不被产品锁定 |
| 不做云输入/联想联网 | 与隐私承诺冲突，宁可候选质量略降 |

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 日语汉字转换质量难达到系统输入法水平 | M2 用 JMdict + 词性连接矩阵（Mozc 同思路）分阶段做；先保证假名可用 |
| HarmonyOS 三方输入法需华为认证 | 从 M3 起准备材料，M5 提交；不阻塞其他平台 |
| iOS 键盘扩展内存上限（约 60-80MB） | 词典 mmap 按需加载，常驻内存预算 < 40MB |
| Windows TSF 复杂度高 | 用 windows-rs 的类型化接口，参考成熟开源实现；单独立项 M3 |
| 双拼方案细节差异（零声母、ü 处理） | 解码端宽容多方案输入，方案表数据化并配校对用例（见 `crates/pinyin`） |

## 7. 度量（本地可见、不上传）

- 冷启动到候选可用 < 80ms；单键延迟 P99 < 8ms（本机统计，仅内存）。
- 整句首候选命中率（自带评测集 `crates/pinyin/tests/`）。
- 安装包体积：macOS < 12MB（含基础词典）。
