# 同步协议 v1（无服务器 · 局域网 P2P）

原则：**没有服务器、没有账号、没有云**。设备之间只在用户显式配对后、且在同一局域网内直连。

## 1. 身份与配对（一次性）

```
设备 A（显示二维码）                     设备 B（扫码）
─────────────────────                   ─────────────────────
生成长期身份密钥对 (Ed25519)              
二维码内容 = { v:1, device_id, name,
   pubkey,               // 长期公钥
   fingerprint,          // BLAKE3(pubkey) 前 8 字节，人工可核对
   psk }                 // 32B 一次性配对码（QR 里带，物理信道传递）
                                          ─→ 保存 A 的公钥+fingerprint+psk
                                            生成自己的身份密钥对
                                            经 mDNS/TCP 回连 A，用 psk 认证
A 显示 6 位数字校验码 ←── 双方各自计算 ──→ B 显示同样 6 位
（双方确认一致 → 互存对方长期公钥，psk 立即销毁）
```

- 二维码即信道：不经过任何网络或云服务。
- 指纹用于防换码攻击；6 位校验码防「二维码被替换」的中间人。
- 配对后 psk 销毁；之后一切通信使用长期公钥双向认证。

## 2. 传输

| 项 | 选择 | 理由 |
|---|---|---|
| 发现 | mDNS（`_inputflow._udp.local`），可全局关闭 | 局域网零配置；关闭后仅支持手输 IP:port |
| 传输 | QUIC（一条连接双向多路） | 0-RTT、抗丢包、方便做多路复用 |
| 安全 | TLS 1.3 双向认证 + 自签证书 pin 到配对公钥 | 无需 CA、无需服务器 |
| 二次封装 | 载荷 AEAD（ChaCha20-Poly1305，会话密钥 HKDF 派生） | 即便 TLS 终结于某个中间盒，内容仍不可读 |
| 端口 | 默认 UDP 45900（可配置） | 避免与常见服务冲突 |

默认关闭自动发现；默认只监听局域网地址，不监听公网网卡。

## 3. 同步内容（op-log）

```rust
enum Op {
  UserWordFreq { key: String, delta: i32, at: Hlc },      // 用户词频增量
  ClipboardItem { id: Hash, text_enc: Bytes, at: Hlc },    // 剪切板（可选开关）
  Setting { key: String, value: String, at: Hlc },         // 词库/方案/快捷键等
  WordBookAdd { key: String, word: String, freq: u32, at: Hlc },
}
```

- **Hlc**：混合逻辑时钟 `(wall_ms, counter, device_id)`——不需要可信时钟即可定序。
- 合并规则：
  - 计数器类（UserWordFreq）：**求和**（G-Counter），天然可交换、可重复投递。
  - 寄存器类（Setting / ClipboardItem 删除）：**LWW**，用 Hlc 比较，平局用 device_id 字典序。
  - 新增类（WordBookAdd）：**并集**，同 key 取较大 freq。
- 所有规则满足交换律/结合律/幂等（见 `crates/sync/tests`），因此乱序、重复、断连都安全。
- **不传输原始按键流**；不上传整份词库，只传增量。

## 4. 状态与冲突

| 场景 | 行为 |
|---|---|
| 两台设备同时改同一设置 | Hlc 后者胜，两端最终一致 |
| 断连多日后重连 | 互发各自 op-log 水位之后的增量（每条 op 保留 HLC，可作水位） |
| 设备丢失 | 在另一台设备上「吊销设备」→ 后续握手拒绝该公钥；已同步内容无法远程擦除（无服务器） |
| 剪切板含敏感内容 | 默认不记录密码框内容；提供「暂停同步 5/30/60 分钟」 |

## 5. 错误与降级

- 握手失败（指纹/证书不符）→ 立即断连并在 UI 明示，不降级为明文。
- 无可用网络/发现失败 → 静默重试（指数退避），不影响本地输入。
- 时钟异常 → Hlc 逻辑时钟兜底，不依赖 NTP。
