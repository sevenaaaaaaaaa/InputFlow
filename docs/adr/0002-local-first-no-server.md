# ADR-0002：本地优先，同步不经过任何服务器

状态：已接受（M0）

## 背景

「不被任何系统、网络监控 + 端到端加密」意味着：不能依赖云词库，也不能为了同步自建中继（那仍然是一台服务器，且是隐私单点）。

## 决策

- 同步 = 二维码配对（物理信道传公钥与一次性 psk）→ 局域网 QUIC + TLS 1.3 双向认证 → 载荷再做一层 AEAD。
- 默认关闭网络发现与同步；默认不监听公网。
- 跨端剪切板属于同步内容的一个 op 类型，默认关闭，可定时暂停。
- 异地/NAT 场景不内建中继；M5 只提供「自托管中继」适配层（默认关闭、用户自己部署），协议保持 E2EE。

## 结果

- 好：无服务器、无账号、无云泄露面；隐私承诺可验证（抓包即可）。
- 代价：异地同步体验依赖用户网络环境；移动端后台限制会降低实时性（Android 需前台服务，iOS 仅键盘激活时可用）。
- 明确否决：自建中继作为默认路径、任何形式的云词库/云候选。
